# 知网高级检索：检索式构造与精准定位

> 依据知网官方检索手册 1.2.1（一框式）、1.2.2（高级检索）、1.2.5（专业检索）。
> 专业检索的完整语法见 [专业检索表达式语法](./cnki-professional-syntax.md)。
>
> **一句话原则**：一个检索框里盲目塞多个长短语是最容易漏检或全噪声的用法。
> 先把研究问题拆成若干“概念组”，再明确检索项、逻辑关系和匹配方式。

## 1. 先选检索方式，再写检索式

| 场景 | 方式 | 命令写法 |
|------|------|---------|
| 单概念探路 | 一框式（主题） | `search "词"` |
| 多概念组合、需精确/模糊与逻辑控制 | 结构化多条件（最多 10 项）/ 同字段组合 | `search "" --condition "字段|逻辑|匹配|值"`（可重复） |
| 跨字段布尔、位置限定 | 专业检索式 | `search "" --professional "表达式"` 或 `search --expr "表达式"` |
| 若干**并列独立**主题各查一轮 | 批量检索（**不是 AND**） | `batch-search "词1" "词2"` |
| 作者/期刊/机构/基金定向 | 高级字段快捷参数 | `search "" --author 张三 --journal "《中国社会科学》"` |

**关键区分**：`batch-search` 是 N 次独立检索后合并，用于扩展覆盖面，**不能**表达“A 且 B”。需要交集时用 `--condition` 或 `--professional` / `--expr`。

## 2. 从研究问题到检索式

### 2.1 拆概念组

1. 拆成 2–4 个必须同时满足的概念块；
2. 每块列同义词、英文对应词、上下位词、常见缩写；
3. 块内“或”（`+` 或 `OR`）、块间“与”（`*` 或 `AND`），明确排除的概念用“非”（`-` 或 `NOT`）。

示例（生成式 AI 广告披露 → 品牌信任）：

| 概念块 | 同义/相关词 |
|--------|------------|
| 生成式 AI 广告 | 生成式AI、生成式人工智能、AIGC、智能广告 |
| 披露 | 披露、告知、标识、透明度 |
| 结果变量（可选） | 品牌信任、消费者信任、广告态度 |

```text
主题：(生成式AI + 生成式人工智能 + AIGC) * (广告 + 营销)
篇名：披露 + 告知 + 标识
```

### 2.2 选检索项与匹配方式

- **主题（`SU`）只提供相关度匹配（`%=`）**，不支持指定精确/模糊；给主题传 `--match 精确/模糊` 会显式报错。
- 其余 15 个检索项支持 `精确` / `模糊`：

| 检索项 | 精确 (`=`) | 模糊 (`%`) |
|--------|-----------|-----------|
| 篇名、摘要、全文、小标题、参考文献、篇关摘（篇名部分） | 检索词作为**整体**匹配 | 分词后匹配 |
| 关键词、作者、第一作者、通讯作者、作者单位、基金、分类号、文献来源、DOI | 字段值**完全一致** | 字段值**包含**检索词 |

因此对关键词、机构、文献来源等字段，未显式指定匹配方式时默认使用 `模糊`，避免因完全一致导致 0 命中。

## 3. 同字段组合运算规则

`*` 与（同时包含）、`+` 或（含其一）、`-` 非（含前者不含后者）：

1. `*`、`+`、`-` **前后必须各空一个字节**（如 `生成式AI + AIGC`；`人工智能+AIGC` 非法）。
2. 单个条件检索框**不超过 120 个字符**，超出请拆为多个 `--condition` 或改用专业检索。
3. 检索词本身含空格或特殊符号时，用**英文半角引号**括起：`'digital library' * 'information service'`、`'2+3' * 人才培养`。
4. 优先级用英文半角括号：`(锻造 + 自由锻) * 裂纹`。

## 4. 中英文扩展控制（`--cross-language`）

知网高级/专业检索默认勾选**中英文扩展**，会使中文检索混入英文文献或同义译词结果。需要纯净中文检索结果时传入 `--cross-language off`：

```bash
# 多条件精准定位 + 关闭中英文扩展
python scripts/literature.py search "" \
  --condition "篇名|并且|模糊|(生成式AI + AIGC)" \
  --condition "关键词|并且|模糊|广告" \
  --condition "摘要|或者|模糊|品牌信任" \
  --cross-language off

# 专业检索表达式
python scripts/literature.py search "" \
  --professional "SU %= (生成式AI + 生成式人工智能) AND KY % (广告 + 营销)"
```

## 5. 核对输出中的 `retrieval` 回显

每次知网检索返回的 JSON 会附带 `retrieval` 字段，记录请求条件、编译后的检索式、中英文扩展实际状态、结果页表达式回读校验（`verified`）及总命中数（`total_hits`）：

- `verified: false` 表示结果页回读表达式与提交不一致，会返回 `CNKI_RETRIEVAL_MISMATCH` 错误，拒绝静默返回失真结果。
- `total_hits: 0` 表示已确认知网真实返回 0 条记录，可用于指导逐级放宽检索条件（字段放宽 → 模糊匹配 → 删减次要概念块）。
