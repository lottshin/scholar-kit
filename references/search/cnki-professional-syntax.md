# 知网专业检索表达式语法

> 依据知网官方检索手册 1.2.5。检索策略与概念组拆解法见
> [知网高级检索：检索式构造与精准定位](./cnki-advanced-retrieval.md)。

## 1. 字段代码

| 代码 | 字段 | 代码 | 字段 |
|------|------|------|------|
| `SU` | 主题 | `AU` | 作者 |
| `TKA` | 篇关摘 | `FI` | 第一作者 / 第一责任人 |
| `TI` | 篇名 / 题名 | `RP` | 通讯作者 |
| `KY` | 关键词 | `AF` | 作者单位 / 机构 |
| `AB` | 摘要 | `JN` / `LY` | 文献来源 / 期刊名称 |
| `FT` | 全文 | `FU` | 基金资助 |
| `CO` | 小标题 | `CLC` | 分类号 |
| `RF` | 参考文献 | `DOI` | DOI |

> 注：出版年度范围推荐优先通过 CLI 参数 `--year-from` / `--year-to` 设定。

## 2. 匹配运算符

| 形式 | 含义 | 适用字段 |
|------|------|---------|
| `= 'str'` | 与 str 完全相等 | `KY AU FI RP JN LY AF FU CLC DOI` |
| `= 'str'` | 包含完整 str | `TI AB FT RF CO` |
| `% 'str'` | 包含完整 str | `KY AU FI RP JN LY FU` |
| `% 'str'` | 包含 str 及其分词 | `TI AB FT RF CO` |
| `%= 'str'` | 主题相关度匹配 | `SU` |

## 3. 字段间逻辑与同字段复合运算

- **字段之间**：`AND` / `OR` / `NOT`（前后必须各空一格）。**注意知网专业检索中 `AND`、`OR`、`NOT` 优先级相同（左结合）**，混合使用时必须加英文圆括号：
  ```text
  AU = 钱伟长 AND (AF % 清华大学 OR AF % 上海大学)
  ```
- **同一字段内部**：`*`（并含）、`+`（或含）、`-`（不含），运算符前后各空一格：
  ```text
  KY % 铝合金 + 钛合金
  FT % 催化剂 * 反应率
  ```

## 4. 位置描述符（仅限 `TI`、`AB`、`FT` 同字段两词之间）

| 描述符 | 含义 | 示例 |
|--------|------|------|
| `#` | 两词同句 | `FT = '人工智能 # 推荐算法'` |
| `/NEAR N` | 同句且相隔不超过 N 个字词 | `FT = '人工智能 /NEAR 10 推荐算法'` |
| `/SEN N` | 同段且句子序号差不大于 N | `AB = '算法 /SEN 2 治理'` |
| `/PRG N` | 相隔不超过 N 段 | `FT = '出版 /PRG 5 法规'` |
| `$ N` | 检索词最少出现 N 次 | `FT = '大数据 $5'` |

## 5. `--condition` 条件编译规则

`--condition` 会先经确定性语法校验，再编译为专业检索式提交并回读校验：

| 条件写法 | 编译结果 |
|---|---|
| `主题\|值` | `SU %= 值`（主题仅相关度匹配） |
| `字段\|并且\|精确\|值` | `CODE = 值` |
| `字段\|并且\|模糊\|值`（或省略匹配方式） | `CODE % 值` |
| `字段\|或者\|匹配\|值` | 与前一条显式加括号组成 `(前式 OR 当前式)` |
| `字段\|不含\|匹配\|值` | 与前一条显式加括号组成 `(前式 NOT 当前式)` |
