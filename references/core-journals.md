# 核心期刊知识

Agent 将用户自然语言翻译为 `--core` 参数时使用此文档。

## 知网侧边栏「来源类别」选项

| 选项 | 全称 | 主办机构 | 学科覆盖 |
|------|------|----------|----------|
| **北大核心** | 《中文核心期刊要目总览》 | 北京大学图书馆 | **全学科**（人文、社科、理工、医学、艺术等），覆盖面最广 |
| **CSSCI** | 中文社会科学引文索引 | 南京大学中国社会科学研究评价中心 | **人文社科**，俗称"南大核心""C刊" |
| **AMI** | 中国人文社会科学期刊AMI综合评价 | 中国社会科学院中国社会科学评价研究院 | **人文社科**，分顶级/权威/核心/扩展档 |
| **CSCD** | 中国科学引文数据库 | 中国科学院文献情报中心 | **自然科学**（理工农医） |
| **WJCI** | 科技期刊世界影响力指数 | 中国科学技术协会 | **科技期刊国际影响力评价**，不等同于传统"核心期刊"认定 |
| **EI** | Engineering Index（工程索引） | Elsevier (国际) | **国际工程技术索引**，不属于国内核心期刊体系 |

## Agent 决策规则

1. **用户明确指定了体系** → 直接传对应选项名
   - "C刊""南核""南大核心" → `--core CSSCI`
   - "北核""北大核心" → `--core 北大核心`
   - "CSCD" → `--core CSCD`

2. **用户说"核心期刊"但未指定体系** → 根据学科判断：
   - 人文社科（文学、历史、哲学、法学、教育、新闻传播、经济、管理、政治、社会学、艺术等）→ `--core 北大核心,CSSCI`
   - 理工农医（数学、物理、化学、生物、计算机、工程、医学、农学等）→ `--core 北大核心,CSCD`
   - 无法判断 → 询问用户，或仅用 `--core 北大核心`

3. **用户要求宽口径** →
   - 人文社科宽口径 → `--core 北大核心,CSSCI,AMI`
   - 全部国内核心 → `--core 北大核心,CSSCI,AMI,CSCD`

4. **EI / WJCI / SCI** → 不属于传统"核心期刊"：
   - "EI期刊" → `--core EI`
   - "SCI期刊" → 知网可能无此选项，建议用 Web of Science

5. **用户未提及核心** → 不传 `--core`

## 注意

- "是否算核心"以用户所在单位科研处规定为准
- 同一期刊可能同时被多个体系收录
- 展示结果时应注明实际筛选了哪些来源类别
